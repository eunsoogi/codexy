# Feedback note

Optional shape for an existing authorized note or artifact. Follow the
[feedback evidence contract](../references/feedback-evidence.md); omit
irrelevant detail, but keep missing information explicitly unknown. This is not
a required file, scoring schema, process/outcome verdict, or rule-promotion
approval.

- Claim and applicable scope:
- Actual observation, or no observation available:
- Source type: actual execution / tool / external data / human / LLM evaluator /
  self-evaluation / simulation / heuristic
- Immediate source and underlying origin:
- Evidence location and relevant original revision, time, environment,
  conditions:
- Confidence: high / medium / low / unknown; reason:
- Independence: independent / shared origin / unknown; basis:
- Limitations, missing provenance, and conflicting evidence:
- Selected response and its authority: independent evidence / safe observation /
  backtrack / lower confidence / no additional observation needed
- Repeated observation, if any: original and new result, conditions, remaining
  uncertainty; distinguish observation from any external side effect
- Decision supported by this evidence and unresolved limits:

MUST NOT turn an unsupported claim into an observation, count repeated citations
as independent corroboration, or treat this note as authority for permanent
harness changes. MUST keep sensitive raw data out of the note.
