Optional shape for an existing authorized note under
[long-work reliability](../references/long-work-reliability.md).

- Task scope, protected goal, success criteria, run unit, observation window:
- Original invocations, revisions, environments, source references, cohort
  limits:
- All observed runs: total; confirmed success / failure / incomplete / aborted /
  unknown outcome; overlapping states explicitly identified:
- Success: confirmed successes / all observed runs; missing outcome limits:
- Failure stage for each evidenced failure, or unknown:
- Recovery definition and attempted recoveries: success / failed / incomplete /
  unknown; success / attempts; unattempted and impossible cases separately:
- Repeated-loop definition: runs with observed loops / all observed runs;
  unknown observations; event counts separate if included:
- Replan counts per run and total, with unavailable counts identified:
- Context loss: stage, evidence, and unresolved effect:
- Goal drift: stage, evidence, and unresolved state:
- Verifier disagreements: claim, evidence, and unresolved state:
- Interpretation limits and next permitted observation:

MUST retain original failures, interruptions, and missing measurements. Ratios
MUST show numerator and denominator; zero recovery attempts MUST NOT become 100
percent recovery. Unknown observations MUST NOT become zero events. This summary
MUST NOT restore goal/ownership state or declare completion.
