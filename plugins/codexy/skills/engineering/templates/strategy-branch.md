# Strategy branch

Optional compact record under
[strategy search](../references/strategy-search.md). Use an existing authorized
note; this does not create a Git branch or app task.

- Candidate identifier and active / stopped status:
- Core premise:
- Method:
- Expected benefit and expected failure mode:
- Substantive difference from the leader or another candidate:
- Expected quality, information value, and novelty (estimates with reasons):
- Evidence strength: actual observations, provenance, confidence, limitations:
- Next-step cost, risk, reversibility, and authority:
- Discriminating observation and expected contribution:
- Disposition reason: retain / expand / refuted premise / repeated failure /
  duplicate of named candidate / exhausted information value / budget ended:
- Supporting evidence and remaining uncertainty:

MUST distinguish estimates from observations and preserve stopped-branch
reasons. MUST NOT label shared-source claims as independent evidence or a budget
stop as proof of failure. The overall set records the retained different
alternative, or why none remains.
